# RefineAI Landing Page

This is the official landing page and legal site for the RefineAI Chrome Extension.

## Features
- **Modern Landing Page**: High-conversion design with feature highlights.
- **Privacy Policy**: Required for Chrome Web Store approval.
- **Terms of Service**: Standard legal framework for AI usage.
- **Vercel Ready**: Optimized for instant deployment.

## Deployment to Vercel

1. Install Vercel CLI: `npm i -g vercel`
2. Navigate to this folder: `cd landing-page`
3. Deploy: `vercel`

Once deployed, copy the production URL and paste it into your Chrome Web Store developer dashboard under "Privacy Policy" and "Official Website".
